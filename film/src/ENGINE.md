# Film engine: how a scene is written

The film is one HyperFrames composition generated by `node src/build.mjs` from:

- `src/film.mjs`: frames and timing (scene length = lead-in + Lily's line + breath).
- `src/runtime.js`: one paused GSAP timeline; the continuous layer (paper/night theme
  blend, HUD with the running index and the LOCAL · 0 B SENT privacy meter, the ruler,
  word-synced captions, chromatic spikes and light leaks on cuts, grain, flicker, aurora).
- `src/film.css`: tokens and shared parts.
- `src/scenes/NN-name.mjs`: one module per scene. **This is what you write.**

Chapter cards (03, 11, 17) are built by the engine. Do not write modules for them.

## The frame you are drawing into

1920x1080. The engine already draws: the plate border (inset 44/40 with corner ticks), the
HUD top-left (`INNERNET · FIELD GUIDE`, chapter line) and top-right (counter, privacy
meter, about x 1500 to 1834, y 60 to 185: the meter pill reaches y 183), the ruler (y 990
to 1035) and the caption line (centred, y 908 to 950). **Keep scene content inside x 110 to 1810, y 150 to 880**, and
never put text where the captions run (y 895 to 960).

Colours come from CSS variables that the runtime blends between day and night:
`--bg --ink --ink2 --muted --link --surface --line --con`. Never hard-code hex colours
(the sigil gradients of real folders are the one exception: `oklch(...)` from the slug).
Fonts: `display` (Instrument Serif), `serif` / `serif-i` (Newsreader), `mono`
(JetBrains Mono), Inter for UI. Sizes are video sizes: display numerals 120 to 260px,
titles 52 to 64px, lines 28 to 34px, mono labels 18 to 24px.

## Module shape

```js
// src/scenes/04-crawl.mjs
export default {
  id: "04",
  css: `#s04 .thing { ... }`,              // optional; scope every rule with #sNN
  html(ctx) { return `...markup...`; },     // the scene's static end-state
  motion(tl, S, T, k, seg, el) { ... },     // GSAP choreography; runs in the browser
  sfx(ctx) { return [{ name: "seal", at: ctx.word("secrets"), vol: 0.35 }]; }, // optional
  extra(ctx) { return ""; },                // optional extra clips (rare)
};
```

- **`html(ctx)`** returns the markup placed inside `#sNN > .scene-in`. Build the visible
  end state first (layout contract), then animate from it. Give every element you animate
  an id or a class scoped under `#sNN`.
  - `ctx.plate(id, cls)` inlines a plate SVG (`assets/plates/<id>.svg`, 1600x1000) ready to
    draw on. Put it in a positioned wrapper that sets its size.
  - `ctx.capture(name)` is the path of a real screen capture in `assets/captures/`
    (`search-linear@2x.png`, `article-linear-clone@2x.png`, `disambiguation-src@2x.png`,
    `home@2x.png`, 3200 px wide; also 1x versions without `@2x`).
  - `ctx.cap(prefix, { big, unit, title, line })` the standard caption block
    (bottom-left: numeral + unit, rule, title, italic line). Animate with
    `k.capBlock(prefix, S)`.
  - `ctx.fig(n, title)` the small "FIG. n · TITLE" line top-left (y 168).
  - `ctx.word("noise")` absolute time of a word in the narration (build-time, for sfx).
  - `ctx.seg` has `start`, `dur`, `voStart`, `vo.text`, `vo.words[]`, `plate`, `fig`.
- **`motion(tl, S, T, k, seg, el)`** is serialised with `toString()` and run in the
  page, so it must be **self-contained**: only use its arguments and browser globals
  (`gsap`, `document`). No imports, no closures over module variables. `S` is the scene's
  absolute start, `T` its duration, `el` the scene element.
  - Every tween is `tl.fromTo(...)` at an absolute position (`S + x`), explicit from and
    to states, transforms/opacity/clip-path/stroke-dashoffset only. Never tween the clip
    element itself (`#sNN`); tween children. No `Math.random`, no `Date`, no `repeat: -1`.
  - First visible motion within 0.2s of `S`. Land reveals on the narration with
    `k.word(seg, "secrets")` (absolute time of that word).
  - The scene must fully settle before it ends; the last 0.3s should be still or a slow
    drift (the engine cuts with a chromatic spike).
- **`sfx(ctx)`**: extra sound marks. Available: `pencil`, `bell`, `keys`, `whoosh`, `seal`,
  `page`, `tick`, `lock`. A mark without `vol` plays at its level in `assets/audio/audio.json`
  (`mix.sfx`). The engine already places whoosh/bell/page on cuts and a pencil at the
  start of every plate scene; add only what the action calls for (keys while typing, a
  seal when something closes, a tick on a counter).

## The kit `k`

| Call | Does |
| --- | --- |
| `k.$(sel, scope)`, `k.$$(sel, scope)` | query helpers |
| `k.word(seg, w, nth)` | absolute time of the nth occurrence of word `w` in this scene's line |
| `k.drawPlate(scopeOrSvg, S, T, { acc, lbl, lblSpan, mainSpread, detSpread, accSpread })` | draws a plate on layer by layer: construction, main, detail, labels, then the accent at `acc` (absolute; default S + T/2). Land `acc` on the key word. `acc: false` leaves the accent layer to the scene; labels fade in over `lblSpan` s (default the shorter of T * 0.3 and 1.6). |
| `k.draw(elsOrScope, at, dur, spread, ease)` | draw any SVG strokes on (shapes need `pathLength="100"`, styled `stroke-dasharray: 100 110`) |
| `k.camera(el, S, T, { from, mid, to, settle, ease })` | settle in from `from` to `mid` over `settle` s, then drift to `to` for the rest |
| `k.capBlock(prefix, S)` | animates `ctx.cap` |
| `k.rise(els, at, { y, dur, stagger })`, `k.fade(els, at, dur)` | soft entrances |
| `k.pop(els, at, { from, stagger })` | spring pop |
| `k.strike(els, at, dur, stagger)` | scaleX 0 to 1 from the left (strikes, underlines, rules) |
| `k.typeOn(el, at, dur)` | types an element's text on |
| `k.countUp(el, at, dur, from, to, fmt)` | counts a number up |
| `k.counter(t, label, value, dur)` | changes the HUD running index at time t (e.g. ARTICLES 958 to 959) |
| `k.pulseMeter(t, dur)` | makes the HUD privacy meter glow (privacy beats) |
| `k.lockHud(t)` | the padlock joins the HUD meter and clicks shut at t (called once, by 07 at its seal) |

### Draw-on rules (the kit handles them; follow them in your own tweens)

- Hide a stroke at `strokeDashoffset: 101` with `stroke-dasharray: 100 110`. At 100 (or with
  `100 100`) a round cap leaves a dot at the end of the path before it draws.
- Chrome restarts the dash pattern on every subpath. `k.draw` and `k.drawPlate` split a path
  of up to 8 subpaths (an arrow and its head) into pieces drawn one after another, and let
  the pieces of a longer one (dashes, hatching, ticks) grow together. Your own tweens on a
  multi-part path need the same care.
- `#content` carries the chromatic filter over an opaque background, so translucent fades
  and halos keep their colour.
- The plates' corner registration marks are tagged `.reg` at build time and hidden.

Callouts over plates or screens: an absolutely positioned `<svg class="callouts">` with
`<path pathLength="100">` lines (styled link blue by `film.css`) drawn with `k.draw`, and
`<div class="callout-label">` labels faded in with `k.rise`. A real screen goes in a
`<div class="mount">` (crop marks, hairline, shadow) with an `<img>`; move the camera on
an inner wrapper, never on the mount's clip.

## Checking your scenes

```bash
node src/build.mjs --only 04,05          # previews/04-05.html
node scripts/frame.mjs previews/04-05.html 20,24,28 .hyperframes/frames/w1 --sheet .hyperframes/frames/w1/sheet.png
```

`frame.mjs` seeks the preview to each absolute time and screenshots it (1920x1080). Look
at the scene at its start (+0.3s), at the key word, and at its settled end (-0.4s). Get
the absolute times from `node src/film.mjs`. Compare against the approved sketch for the
frame (`storyboard-v2.png`, `storyboard.html#frame-NN`): the confirmed layout is kept and
dressed, never redrawn. Then run `npx hyperframes lint` from the project root (it reads
`index.html`; rebuild it with `node src/build.mjs` first) and fix anything in your scenes.
